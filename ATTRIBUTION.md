# Attribution

## This project

Melbourne Miniature is an original, from-scratch build. The compressed geography (the Yarra channel,
the two banks, the bay wedge), the Hoddle Grid and named streets, the eight landmark models and
their anchors, the nine ordinary building families, the transport, the English/Vietnamese copy, the
plan/geometry tests and the browser verification targets were all authored for Melbourne. No scene
files, coordinates, street names, landmark models, strings or test values were copied from the San
Francisco or Bangkok miniatures, or from the Manhattan sample.

## Mechanism lineage

The construction pattern — road-first plan, instanced facades, camera flights, a virtual clock, a
capture API, a single-file build and a headless verification gate — follows the **City Miniature**
skill and its San Francisco reference implementation. That reference derives from the **Manhattan
Miniature 0.2.0** sample by **SandBase Lab** (<https://www.sandbase.ai>). The original brand mark is
not redistributed. The San Francisco reference is used as a mechanism catalogue only.

The Melbourne scene includes no San Francisco or Manhattan scene content.

## Dependencies

The runtime bundles **three.js**, **React**, **React DOM** and **scheduler**, all MIT-licensed. The
development stack (Vite, TypeScript, Playwright Core, tsx, React types) is used only to build and
test. The single file carries the production licence texts in its head comment, generated by
`scripts/notices.mjs`; `dist/THIRD_PARTY_NOTICES.txt` is the same text.

## Imagery

The screenshots in `docs/` are renders of this project. The scene uses only procedural geometry,
system fonts and generated colours; it contains no photographic or third-party map imagery.
